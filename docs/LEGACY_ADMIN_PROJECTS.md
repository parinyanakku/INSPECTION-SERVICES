Project search is cleared after creating/importing/restoring projects. Search has explicit clear control and autofill hints. After verified login, only the original owner admin UID can automatically merge pre-login localStorage project data into their own IndexedDB; matching IDs with different contents are copied rather than overwritten. All writes and import marker are atomic. No raw legacy data is uploaded or removed. Other accounts do not import legacy data, and demo reset is hidden for customers. Unauthenticated archived builds remain in the archive branch but are not copied to new public Pages deployments; direct old entry points redirect to login. Old locally cached copies, public repository sample content and browser DevTools are not a confidentiality boundary. Actual legacy data exists only where it was saved; other devices require backup/import. Do not clear browser storage.
