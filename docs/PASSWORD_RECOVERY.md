# Password change and recovery
Authenticated password change reauthenticates the existing account using its old password, verifies the user ID, and updates the password via Supabase Auth. It does not change the license or IndexedDB. No forced rotation is implemented. Recovery uses a stable root reset-password.html URL and a PKCE verifier stored temporarily in the requesting browser; open the email link in the same browser profile. The access token is memory-only. 
Required hosted Auth configuration: add exact redirect URL https://teaminspectionproelite.github.io/INSPECTION-SERVICES/reset-password.html in Authentication > URL Configuration. Keep the standard recovery email template using ConfirmationURL. Configure custom SMTP in Authentication > Emails > SMTP Settings; built-in SMTP only sends to project team members. No billing upgrade performed. Test with a non-admin customer before advertising email recovery.
