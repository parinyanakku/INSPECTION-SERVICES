Unified login: the active workspace session is shared with the admin panel. Admin-only RPCs still validate current role on the database. New accounts are created using Supabase Authentication, not a browser service key. The old root auth-preview URL redirects to the latest account-scoped release without changing the preferred release. Existing archived releases are immutable and retain their original UI. Local project storage is unchanged. Password reset, device limits, and protection against copying public frontend code are not implemented.
