# ProElite Inspection packages — admin distribution / native-window pilot

The existing web workspace and customer-report links remain available during migration. The new Windows and Android packages are experimental embedded WebView clients of the existing Pages application, not independent bundled applications or native-only authorization. They do not start Edge or Chrome to open the workspace. Windows has an isolated WebView2 profile; Android has isolated WebView storage. Sign in again and use a verified JSON backup to restore data only after testing. Google Drive OAuth inside embedded webviews, camera capture, downloads, offline operation and native signed updates are not certified; Android file export is explicitly unsupported in this pilot. iPhone/iPad remain PWA during the transition.

## Build and distribution
- Windows: per-user x64 MSI, .NET Framework and WebView2 runtime. Build with native/windows/build.ps1 using -WixBin, -WebViewBin (pinned Microsoft.Web.WebView2 NuGet), -BuildNumber. Sign and test before approval.
- Android: native WebView APK, JDK 17, platform 35/build-tools 35.0.0. Test APK has an ephemeral key. Production requires an owner-controlled release keystore and compatible version code. See native/android/build.ps1.
- iOS: native distribution is not implemented. Do not promise an unsigned IPA or turn off browser access for existing iOS buyers.

## Admin-only installer distribution
The private bucket proelite-installers is not public. Its existing SELECT policy evaluates inspection_can_download() on every listing/read. The 20261128092459 migration changes that function to require an active administrator license. Buyers cannot list or download approved installers, including via a direct authenticated object URL. Existing buyer license access to their workspace is unchanged. The admin prepares an approved file in the download center, then saves or uses the phone share sheet; no automatic message is sent. Downloaded files may be copied; installation is not proof of purchase.

The native workflow compiles and verifies candidates, discards default outputs and never publishes public artifacts. Manual staging requires short-lived owner-generated candidate upload URLs in PROELITE_WINDOWS_CANDIDATE_UPLOAD_URL and PROELITE_ANDROID_CANDIDATE_UPLOAD_URL; Android release signing also requires PROELITE_KEYSTORE_BASE64, PROELITE_KEY_ALIAS, PROELITE_STORE_PASSWORD and PROELITE_KEY_PASSWORD. Keep the key outside the repository. After signatures, actual device tests, and owner approval, upload to approved/ProElite-Inspection.msi or approved/ProElite-Inspection.apk. Do not upload the pilot as an approved package until feature compatibility is verified.

## Native-only cutover gate
No browser-only rejection is active. A public web app and a user-agent/custom header are not reliable proof of native execution. Before disabling browser workspace access, implement bundled builds, registered device keys with server-side challenge verification and a separately protected application API, native-safe Google OAuth, secure update signing, and a migration/rollback plan for existing local workspaces. Test Windows/Android/iOS and obtain owner approval before removing old access. The customer report viewer remains public via its original authorized expiring links, and administrators need a separate distribution surface. No protection can guarantee that a distributed client cannot be reverse engineered.

## Admin test downloads
Main-branch native package builds stage TEST MSI/APK into a fixed private candidates/test path via GitHub OIDC (repository/owner IDs, workflow, main branch, issuer, audience, timestamps and signature validated). No permanent upload key is placed in GitHub. The edge endpoint checks inspection_can_download with the caller's JWT before returning test files; the public bucket flag stays false. The test packages are not approved, Windows is unsigned and the Android test key can change. Approved paths and manual distribution remain unchanged. The download center deliberately hides sharing for test files. Do not distribute these candidates.
