# Account-scoped local workspace (storage schema 2)
New builds require email/password authentication and current server-side license approval before opening local data. Each account uses a distinct IndexedDB database. Projects, photos, report book data, brand, language and Gemini settings stay on this device. Supabase receives authentication and license requests only. AI analysis still sends a reduced image to Google Gemini on explicit request. No automatic migration from the unscoped legacy localStorage is performed; export a backup in the older release and import it in the signed-in workspace. Legacy releases remain usable and their old localStorage data remains present; they do not use the new IndexedDB database. New release picker excludes legacy versions. Local databases are not encrypted against someone with access to the same OS/browser profile or DevTools. No synchronization or recovery after clearing browser storage; keep external backups. Auth tokens are held only in memory, so refresh requires sign-in. Access is checked at sign-in and every 60 seconds while running; network failure blocks the workspace. This does not protect public client code from copying/bypassing and is not complete commercial DRM. The user must still manage licenses from the existing auth preview. Test account switching, persistence, backup/restore, expired license, and actual report export before production sales.
