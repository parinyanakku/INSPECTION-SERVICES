# Optional website releases
Each successful archive build uses the GitHub Actions run number as the patch version (v1.0.N). The pages-versions branch stores built releases; do not edit or delete it. Root Pages URL redirects to the release chosen in localStorage. Releases share the same origin and existing inspection data. No automatic schema migration is implemented; future incompatible schema changes must be handled before allowing rollback. Backup downloads include live projects, brand and report book data, but exclude credentials. The user confirms the file is saved before changing versions. Existing unversioned builds cannot be recovered retroactively. Monitor Pages/repository storage usage as archives accumulate. This mechanism is not an authentication or licensing control.
